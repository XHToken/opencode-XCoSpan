# XHToken Community Code of Conduct

This project follows the [XHToken Community Code of Conduct](https://github.com/XHToken/community/blob/main/CODE-OF-CONDUCT.md). It applies to contributors, maintainers, and participants in repository discussions, reviews, and community spaces.

## Standards

Treat others with respect, welcome constructive feedback, and respect differing experiences and perspectives. Harassment, discrimination, threats, retaliation, and publication of private information violate the community standards. The linked community policy defines the full scope, standards, and enforcement process.

## Reporting

Report conduct concerns privately to the XHToken Code of Conduct Committee at [tokenspark-org@googlegroups.com](mailto:tokenspark-org@googlegroups.com). Include relevant links and context, and keep sensitive incident details out of public discussions.

For software vulnerabilities, follow [Security](SECURITY.md).
